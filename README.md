My current focus is reproducible biomedical ML: small, well-documented research codebases, clear baselines, careful validation, and readable scientific notes. I am especially interested in models that connect biological data with practical questions in drug discovery and brain research.

- Biomedical machine learning: reproducible pipelines, uncertainty, interpretable baselines
- Scientific software: clean README files, runnable notebooks, documented datasets, archived releases
